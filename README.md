# Student Management System

## Project Description

A Python-based Student Management System developed to manage student records efficiently. The system provides options to add, view, update, delete, and search student information.

## Features

- Add Student
- View Students
- Update Student
- Delete Student
- Search Student
- Exception Handling
- Object-Oriented Programming
- File Handling
- Simple Menu-Based Interface

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- File Handling

## How to Run

1. Download or clone this repository.
2. Open the project in Python or an IDE.
3. Run `student_management_system.py`.
4. Follow the menu options displayed on the screen.
